03 / MEMORY LAB

Explore Structure Memory

Compare hypothetical tight packing, the common aligned layout, and layouts after reordering members.

Know what the simulation means

struct Data {
    char a;
    int b;
};

Padding is unused space inserted to satisfy alignment. It is not a declared structure member. The compiler and platform determine actual layout.

This is a conceptual memory visualization, not a byte-accurate hardware memory debugger. The hypothetical packed view does not describe an assumed default structure layout.
